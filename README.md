# Spotify Clone

A music streaming web application built to practise front-end development.

## About the Project
This project recreates a Spotify-inspired music player interface using front-end web technologies.

## Features
- Music player interface
- Play and pause functionality
- Audio progress bar

## Technologies Used
- HTML5
- CSS3
- JavaScript

## What I Learned
- DOM manipulation and event handling
- Working with audio in JavaScript
- Styling responsive web layouts

## Getting Started
1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
